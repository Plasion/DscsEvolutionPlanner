# DscsEvolutionPlanner

《数码兽物语 网络侦探》进化路线规划器（命令行版）。

给定起点和终点数码兽，在「退化 / 进化」关系图上搜索前 k 条最优路线，支持排除世代、要求途经指定数码兽、要求沿途收集指定继承技等约束。

---

## 环境要求

- **Python 3.12 或更高**（`planner.py` 里用到了 PEP 701 的嵌套引号 f-string 语法，3.11 及以下会报语法错误）
- 依赖：
  - [`mohu`](https://pypi.org/project/mohu/) —— 数码兽名字 / 世代 / 继承技的模糊匹配
  - `pypinyin` —— mohu 的依赖，随 mohu 一起装

```powershell
pip install mohu
```

## 运行

**必须在项目根目录运行**（`data.csv` 是按相对路径读取的）：

```powershell
cd F:\project\projectPy\DscsEvolutionPlanner
python planner.py 亚古兽 战斗暴龙兽
```

> Windows 上如果 `python` 指向的是应用商店占位符，用解释器全路径，例如：
> `C:\Users\<你>\AppData\Local\Python\bin\python.exe planner.py ...`

两种运行方式：

| 方式 | 说明 |
| --- | --- |
| 带参数 | 执行一次后退出，适合脚本调用 |
| 不带参数 | 进入交互模式，提示符 `>>>`，反复输入命令；输入 `-e` / `--exit` 退出 |

## 用法

```
<起点数码兽id或名字> <<终点数码兽id或名字> | -em <终点数码兽id或名字> [更多数码兽...] | -a>
                     [-r] [-k <需要的路径数量>] [-d <要排除的世代> [更多世代...]]
                     [<-pm <途径数码兽id或名字> [更多数码兽...]> [更多途经组...]]
                     [-ps <途径数码兽需要具有的继承技> [更多继承技...]]
```

起点、终点、途经点既可以写**编号**（如 `18`），也可以写**名字**（如 `亚古兽`），名字支持模糊匹配（错字、拼音都能认，见下文）。

### 参数

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| 起点 | 是 | 数码兽编号或名字 |
| 终点 | 见下 | 默认写法：紧随起点给出终点编号或名字 |
| `-em` | 三选一 | 替代默认终点，其后的多只数码兽**任意一只**都可以作为终点 |
| `-a` | 三选一 | 替代默认终点，**任意**数码兽都可以作为终点；必须配合 `-pm` 或 `-ps` 使用 |
| `-r` | 否 | 翻转路线显示顺序，用于「多起点 → 一终点」的查看方式 |
| `-k` | 否 | 求前多少条最优路径，默认 `3`，最小 `1` |
| `-d` | 否 | 禁止其后的多个世代参与计算（如 `-d 究极体 超究极体`） |
| `-pm` | 否 | 要求路线必须**途经**其后的多只数码兽之一；可重复使用以添加多个途经组（组与组之间是「与」） |
| `-ps` | 否 | 要求路线必须能收集其后的**所有**继承技；`2`、`II`、`ii` 等价，表示 `Ⅱ` |
| `-h` / `-?` / `--help` | 否 | 打印内嵌帮助 |
| `-e` / `--exit` | 否 | 退出（交互模式下有效） |

### 示例

**1. 最基本：起点 → 终点，取前 3 条**

```powershell
python planner.py 亚古兽 战斗暴龙兽 -k 3
```

```
进化路线1：[18]亚古兽↗ [90]暴龙兽↗ [203]机械暴龙兽↗ [228]战斗暴龙兽
进化路线2：[18]亚古兽↗ [90]暴龙兽↗ [203]机械暴龙兽↗ [230]凯王兽↘ [204]机械暴龙兽（蓝）↗ [228]战斗暴龙兽
进化路线3：[18]亚古兽↗ [90]暴龙兽↗ [203]机械暴龙兽↘ [75]飞龙兽↘ [56]麻鹰兽↗ [131]火焰兽↗ [199]豆豆兽↗ [228]战斗暴龙兽
```

箭头含义：`↗` 进化、`↘` 退化、`⮂` 形态转换（两方互为进化关系）、`→` 异常回落。

**2. 多终点：`-em`**

```powershell
python planner.py 亚古兽 -em 战斗暴龙兽 闪光暴龙兽 -k 2
```

**3. 任意终点 + 途经约束：`-a` + `-pm`**

```powershell
python planner.py 1 -a -pm 亚古兽 -k 2
```

```
进化路线1：[1]水母兽↗ [10]指爪兽↗ [19]亚古兽（黑）↗ [114]巨龙兽↘ [18]亚古兽
进化路线2：[1]水母兽↗ [10]指爪兽↗ [19]亚古兽（黑）↗ [88]古拉兽↘ [29]基尔兽↘ [7]滚球兽↗ [18]亚古兽
```

**4. 收集继承技：`-a` + `-ps`**

```powershell
python planner.py 亚古兽 -a -ps 物理耗竭 -k 2
```

**5. 排除世代：`-d`**

```powershell
python planner.py 亚古兽 战斗暴龙兽 -d 究极体 -k 2
# 错误：找不到可用进化路线   ← 因为终点战斗暴龙兽本身属于究极体，被排除了
```

**6. 翻转显示：`-r`**（把「一终点」变成「一起点」视角）

```powershell
python planner.py 战斗暴龙兽 亚古兽 -r -k 1
```

### 模糊匹配

起止点、途经数码兽走 `name_matcher`，世代走 `gen_matcher`，继承技走 `skill_matcher`，三者都是 `mohu.MohuMatcher`（`similarity_threshold=0.6`，拼音 + 汉字混合打分）。所以下面这些写法都能命中 `亚古兽`：

```powershell
python planner.py yagushou 战斗暴龙兽    # 拼音
python planner.py 压古兽 战斗暴龙兽       # 错字
```

匹配不到时会明确报错，例如 `错误：找不到起点数码兽「xxx」。`

## 工作原理

1. **建图**：`load_data()` 读 `data.csv` → `link_graph`（双向邻接表，由「退化」+「进化」列合并而成，缺边会自动补全并打印警告）。BFS 遍历时会跳过已不在图中的节点，以此实现 `-d` 的世代过滤。
2. **状态压缩**：`-pm` 每出现一组占 1 个二进制位，`-ps` 每个继承技占 1 位，途经对应数码兽时把该位置 1。`end_state = (1 << state_count) - 1`，要求终点时所有位都已置 1。所以 `-pm` 多组之间是「与」，同组内多只是「或」；`-ps` 列出的技必须全部收集到。
3. **BFS + Yen 算法**：`bfs_search()` 在 `(节点, 状态)` 二元组上做 BFS（按节点数计的最短），`yen_search()` 用它迭代求前 k 条路径，用禁止边 / 禁止节点实现偏离。
4. **输出**：`generate_output_text()` 根据相邻两点的退化 / 进化关系选箭头。

## data.csv 格式

UTF-8 编码，第一行表头，共 341 条数码兽。`planner.py` 实际用到这些列：

| 列 | 用途 |
| --- | --- |
| `编号` | 唯一 id，图里的节点号 |
| `名字` | 主名称，用于匹配和输出 |
| `别名` | 可选，会一起加入名字匹配表 |
| `世代` | 如 `成长期`、`究极体`，供 `-d` / `-d` 匹配使用 |
| `退化` | Python 字面量列表，元素为**名字**（如 `['滚球兽', '汪喵兽']`） |
| `进化` | 同上 |
| `继承技` | Python 字面量列表，元素格式为 `Lv5.技能名`，取 `.` 后半段作为技能名（如 `['Lv5.物理耗竭']`） |

其余列（种族、属性、数值、必杀技等）目前只被读入不参与计算。

**注意**：`退化` / `进化` 里写的是名字，如果某个名字在表中不存在（或存在错别字），`load_data()` 会直接抛 `KeyError`。

## 已知行为与注意事项

- 启动时若打印 `警告：[xx]xxx 进退化表不完整，已临时进行补全`，说明数据源里存在单向关系，程序已自动双向补全，不影响使用。
- `-a` 必须配 `-pm` 或 `-ps`，否则报错退出（避免无约束的全图搜索）。
- `-d` 排掉终点所属世代会直接导致无解，这是预期行为。
- 路线按**经过的节点数**排序（`k` 条不一定互不相同的前缀之外的路径），不是按战斗强度或等级。
- 名字匹配阈值固定为 0.6，写死在 `planner.py` 顶部；想放宽 / 收紧改那三个 `MohuMatcher(...)` 即可。
- 结果不会去重到「同一条路线不同显示顺序」，但内部用元组集合做了精确去重。
